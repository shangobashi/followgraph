Problem

The Following limit turns your graph into a chore.

When you hit a Following limit on X, the obvious fix is to unfollow accounts. But the actual workflow is awful. You scroll through an endless virtualized list. You open accounts one by one. You check who is inactive. You try to remember why you followed someone. You remove a few accounts. Then you lose track and start guessing.

That is not graph management. That is manual excavation. FollowGraph fixes the painful part: it turns the Following page into a file you can actually work with.

Product

From endless scroll to usable graph. FollowGraph scans your Following page, extracts accounts during the scroll loop, dedupes locally, saves progress, enriches useful activity signals, and exports CSV/JSON.

Cleanup

FollowGraph does the ugly part for you. Turn the trapped list into data so you can sort, filter, audit, and decide who still belongs in your graph.

Output

Export files you can actually use. CSV is ideal for spreadsheets, sorting, filtering, quick cleanup, and manual review. JSON is ideal for scripts, notebooks, dashboards, databases, or deeper graph analysis.

Install

Install in two minutes.

FollowGraph is currently distributed as a prebuilt extension zip while the product is in early beta. Download it, unzip it, enable Developer Mode in Chrome or Edge, and load the unpacked extension folder. Developers can inspect the source or build it locally from GitHub.

Download Prebuilt Zip View Source on GitHub
No-code install: download, unzip, load unpacked. Dev install: npm install, npm run build.
  1. Download the Extension Zip.
  2. Unzip it somewhere permanent.
  3. Open chrome://extensions or the Edge extensions page.
  4. Enable Developer Mode.
  5. Click Load unpacked.
  6. Select the unzipped extension/ folder.
  7. Open your X/Twitter Following page.
  8. Start the scan from the extension popup.

Beta

Free early beta.

FollowGraph is free during early beta because real graphs are the only honest test. The scanner is already built for virtualized Following lists, incremental extraction, local checkpointing, enrichment, and CSV/JSON export. But X changes its interface often. Edge cases can break.
