FollowGraph is a privacy-first browser extension for exporting, auditing, and analyzing X/Twitter following graphs. It converts the Following page into clean CSV and JSON files that users can sort, filter, archive, and inspect outside the X interface.

Built for users who have outgrown manual graph cleanup, FollowGraph makes it easier to review large following lists, identify stale or low-signal accounts, preserve network context, and understand the attention graph behind the feed.

Problem

Following graphs are valuable, but the interface makes them hard to manage.

X/Twitter following lists can become large, noisy, and difficult to audit. Users who hit following limits, change focus, shift markets, or need cleaner source lists often face the same inefficient workflow: scroll through a virtualized list, open profiles manually, check relevance one account at a time, and lose context halfway through the process.

That workflow does not scale. FollowGraph replaces endless manual review with a portable graph export users can inspect properly.

Product

Private export and audit for the X/Twitter following graph.

FollowGraph scans the user's own X/Twitter Following page in the browser, extracts accounts during the scroll loop, deduplicates results, saves local progress, and exports the graph as CSV and JSON. The result is a portable dataset that can be reviewed in spreadsheets, scripts, notebooks, dashboards, databases, or internal analysis workflows.

Architecture

Designed for the way X actually loads following lists.

X/Twitter does not expose large following lists as a simple static page. The interface loads accounts dynamically as users scroll. FollowGraph is designed around that reality: it extracts accounts during the scrolling process, deduplicates results, saves progress locally, and produces structured exports from a list that would otherwise remain difficult to inspect.

Browser-side scan workflow Virtualized-list-aware extraction Local deduplication Local progress storage CSV and JSON output Chrome and Edge extension support No OAuth dependency No backend graph database

Privacy

The graph stays local.

FollowGraph is designed around a simple privacy model: the user's following graph should not need to leave their machine in order to become useful. The extension scans locally in the browser, stores progress locally, and generates exports locally.

01

No account handoff

No OAuth login, no account credential collection, and no remote account connection.

02

No graph upload

No server upload, no backend graph storage, and no analytics pipeline collecting the following list.

03

Local workflow

Scanning, progress storage, and export generation happen locally in the browser.

No OAuth login No server upload No account credential collection No backend graph storage No analytics pipeline collecting the following list Local scan Local progress Local export

FollowGraph is for inspecting the user's own following graph, not for automating engagement or collecting private third-party data.

Beta

Free early beta, hardened against real graphs.

FollowGraph is currently available as a free early beta. The goal is to test the extension against real following graphs, real browser environments, and real edge cases.

The current beta supports client-side scanning, local progress, CSV/JSON export, and Chrome/Edge installation. Because X/Twitter changes its interface frequently, some edge cases may break and should be reported.

Install

Install the beta in two minutes.

FollowGraph is currently distributed as a prebuilt extension zip during beta. Users can install it through the standard unpacked-extension flow in Chrome or Edge.

Download Prebuilt Zip View Source on GitHub
No-code install: download, unzip, load unpacked. Dev install: npm install, npm run build.
  1. Download the Extension Zip.
  2. Unzip it somewhere permanent.
  3. Open chrome://extensions or the Edge extensions page.
  4. Enable Developer Mode.
  5. Click Load unpacked.
  6. Select the unzipped extension/ folder.
  7. Open your X/Twitter Following page.
  8. Start the scan from the extension popup.
