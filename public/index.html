Why it lands

Built for the way X actually loads your following list.

X does not expose your full Following page as one simple static list. Accounts appear and disappear as the page scrolls. FollowGraph extracts accounts during the scroll loop, dedupes them locally, saves progress as it goes, and then resolves profile activity through a hardened enrichment pipeline.

Privacy model

FollowGraph runs in your browser. Your following graph is scanned locally, saved locally, and exported locally. No OAuth, backend database, or remote enrichment server.

Output you can use

CSV for spreadsheets. JSON for systems. Use CSV for quick review, or JSON for scripts, dashboards, notebooks, databases, and your own analysis pipeline.

Portable graph

Leave with a file, not a trapped social graph. FollowGraph gives you clean CSV/JSON exports instead of making your network context depend on a scrolling feed.

What early beta means

Free while the product is hardened in public.

01

Built for large lists

The scanner is already built for large X/Twitter following lists, streaming extraction, saved local progress, and CSV/JSON export.

02

X changes often

Edge cases can break when X changes its interface. If a scan behaves strangely, report the issue, browser, rough graph size, and screenshot if possible.

03

No affiliation

FollowGraph is not affiliated with X or Twitter. It does not automate following, unfollowing, liking, posting, or messaging.

FollowGraph only helps you export and inspect your own following graph. It is not an engagement automation tool and does not access other people's private data.

How it feels

A small, sharp workflow designed like a tool.

01

Open your Following page.

Go to `x.com/<you>/following` or `twitter.com/<you>/following` and let the extension target the live page.

02

Trigger the scan.

The popup injects only when you ask. The overlay reports extraction, delay, idle rounds, and live counts.

03

Let v1.4.2 beta resolve activity through captured API data.

As soon as accounts are captured, FollowGraph uses rest IDs and API lanes first, keeps local snapshots updated in batches, and falls back to helper tabs only where needed.

Install

Install in two minutes.

The fastest path is the prebuilt zip. Download it, unzip it, enable Developer Mode in Chrome or Edge, and load the unpacked extension folder. Developers can inspect the source or build it locally from GitHub.

Download Prebuilt Zip View Source on GitHub
No-code install: download, unzip, load unpacked. Dev install: npm install, npm run build.
  1. Download the Extension Zip.
  2. Unzip it somewhere permanent.
  3. Open chrome://extensions or the Edge extensions page.
  4. Enable Developer Mode.
  5. Click Load unpacked.
  6. Select the unzipped extension/ folder.
  7. Open your X/Twitter Following page and start the scan from the extension popup.
