# Beta Tester Program Brief

## Goal
Build early proof through users who actually run a real scan and share trustworthy feedback.

## Offer
- direct access to latest zip
- weekly progress check-ins via async form/issue template
- public credit in campaign notes if they consent

## Ask
- complete one real scan on a real Following page
- note resolution rate, speed, crash/failure points
- answer three quick questions:
  1. what job were you trying to do?
  2. did the first run make sense?
  3. what almost made you quit?

## Qualification
- has real need to inspect/ex Following data
- willing to share one public artifact or quote
- can run in Chrome or Edge

## Recruiting channels
- direct outreach to 50-100 targeted accounts
- HN/Reddit launch opt-ins
- tool-nerd/creator microcommunities
