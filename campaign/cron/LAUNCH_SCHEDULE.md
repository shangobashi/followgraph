# Launch Scheduling

## Day 1
- Repo setup: README refresh, OG tags, screenshot placeholder badges
- Create beta tester signup link or issue template draft
- Prepare first post artifacts

## Day 2
- Post HN Show HN thread
- Post first value-first Reddit thread in targeted sub
- Prepare follow-up comments and answer queue

## Day 3
- Twitter/X thread
- DM beta outreach to 20-30 creators/operators/growth people
- Repo watch/clone observation

## Day 4
- Reddit engineering thread or case thread
- Feedback collection and FAQ/doc updates
- Repo stars/watch feedback loop

## Day 5
- User-generated artifact prompt:
  “Export your following graph and share one insight you found.”

## Day 6-7
- Iterate messaging based on first replies
- Update copy/docs based on actual objections
- Prepare POI list for HN/Reddit feedback response

## Ongoing cadence
- Daily reply sweep on launch posts for 7 days
- Weekly follow-up threads with extracted insight examples
