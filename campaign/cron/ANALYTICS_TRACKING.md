# Analytics & Measurement Package

## Core Metrics
- downloads from followgraph.issalabs.xyz
- GitHub stars, forks, watchers, clones
- referral sources by post/thread
- beta tester signups/requests
- feedback themes count by objection

## Instrumentation
- add UTM tags to launch posts
- note GitHub traffic sources
- log feedback notes by source

## Logging
Create `campaign/logs/YYYY-MM-DD.md` daily with:
- posts published
- referral counts
- engagement signals
- feedback notes

## Success Thresholds
- Day 3: first external referral beyond personal networks
- Day 7: first beta tester run
- Day 14: first meaningful feedback with repeat-use intent
