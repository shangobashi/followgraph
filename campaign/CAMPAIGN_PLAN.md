# FOLLOWGRAPH TRACTION CAMPAIGN PLAN

## Diagnosis
- Status: Living repo on GitHub with active commits, but no public adoption artifacts beyond a private prebuilt zip
- Product: FollowGraph v1.3.7
- Headline capability: Privacy-first local scan and export of a user's own X/Twitter Following list, with captured API enrichment, restId persistence, cursor-aware completion, checkpoint recovery, CSV/JSON export, no separate OAuth/tracking/server dependency
- Immediate issue: Product is decent, but discoverability and trust signals are near zero; install path is hidden; story is not obviously framed around pain relief

## Campaign Name
Radar for Your Following List

## Hypothesis
Users do not wake up wanting a graph tool. They wake up trying to clean up a noisy Following list, find people they lost, inspect someone's network, or prepare outreach/social-audit data. FollowGraph can win by becoming the straightforward, private answer to those specific jobs.

## Primary Personas
1. Creator/operator who accumulated too many follows and wants to audit
2. Growth person who wants to inspect prospect/community/influencer connections
3. Power user/researcher who needs following data for analysis
4. Dev/tool nerd who cares about client-side resilience and X engineering

## Positioning Line
"Don't scroll your way out of a messy Following list. Scan it, resolve it, export it."

## Core Themes
- no server touch
- resumes after X failures
- works against virtualized React lists
- exports CSV + JSON
- built for real X behavior, not a fragile fantasy DOM
- privacy-first, open source, polished UX
