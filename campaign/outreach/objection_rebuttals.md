# Objection Rebuttals

## “Why not just use the official export?”
X/Twitter does not provide a clean following export. The web UI is an infinite-scroll list with no bulk download, context preservation, or activity review.

## “Is this safe / malware?”
Source is open under MIT. Build it yourself or inspect the packaged `extension/` folder. No remote account access, no OAuth, no telemetry.

## “It looks like a scraper.”
It is closer to a browser-assisted local export. Extraction uses the live Following page context; enrichment uses local browser helpers, not hosted scrapers.

## “I’m not technical.”
Non-dev install is four steps. If those steps are unclear, that’s a wording/UX issue I can fix quickly.

## “What’s the business model?”
Early beta is free. Paid model is not required for traction; useful tools can earn trust before monetization.
